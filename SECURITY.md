# Security

STRATA-Bench is an evaluation harness. It does not execute model-generated code.

Please do **not** open public issues for:

- Accidental commits of live-track credentials
- Accidental commits of real paywalled tables (they must never enter this repo)

Email movahedi.m@northeastern.edu. Rotate anything leaked.

The sandbox corpus is synthetic. If you believe a file here is a copyrighted extract from a real board or consultancy, open an issue with `legal` in the title and we will remove it.

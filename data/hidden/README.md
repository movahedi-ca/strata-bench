# Hidden gold

`gold.json` is generated by `scripts/generate_sandbox.py` and is **used by the harness**. It is in-tree in v1.0 so researchers can evaluate locally without a hosted oracle.

**Do not** put this directory on an agent’s tool path. A future hosted leaderboard will replace in-tree gold with a SHA-256 manifest and a private scorer.

To audit integrity after generation:

```bash
python - <<'PY'
from pathlib import Path
import hashlib
p = Path("data/hidden/gold.json")
print(hashlib.sha256(p.read_bytes()).hexdigest(), p.stat().st_size)
PY
```
